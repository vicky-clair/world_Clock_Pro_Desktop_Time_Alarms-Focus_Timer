## 简体中文版：World Clock Pro: Desktop Time, Alarms & Focus Timer 隐私政策

**生效日期：2026年11月6日**  
**最后更新：2026年11月6日**

感谢您使用 **World Clock Pro: Desktop Time, Alarms & Focus Timer**（以下简称“本应用”）。我们高度重视您的隐私保护。本隐私政策旨在清晰说明本应用如何处理您的数据。

### 1. 我们不收集任何个人身份信息
本应用是一款**纯本地运行的桌面工具软件**：
* 我们**不会**收集、上传、存储或分享您的姓名、电子邮件地址、电话号码、设备标识符、地理位置或任何其他个人身份信息。
* 本应用**不包含**任何第三方广告 SDK、行为追踪器或遥测分析代码。
* 本应用无需注册账号即可完整使用全部功能。

### 2. 本地数据存储与配置
为了保存您的个性化设置（例如：添加的世界时钟城市列表、闹钟设置、主题配色、语言偏好以及所选本地壁纸的文件路径），本应用仅在您的 Windows 设备本地用户配置目录（`%APPDATA%\WorldClockPro` 或应用沙盒本地目录）中读写配置文件（`settings.json`）。
* 上述数据完全保存在您的本地计算机上，绝不会离开您的设备。
* 您可以随时通过卸载本应用或删除本地配置文件夹来彻底清除这些数据。

### 3. 本地图片与文件夹访问权限说明
当您使用“本地壁纸”或“壁纸轮播图”功能时：
* 本应用仅在您主动通过系统文件选择器挑选图片/文件夹、或主动将图片拖入应用窗口时，读取您所选定的本地图像文件（`.png`、`.jpg`、`.jpeg`、`.bmp`）用于在本地屏幕渲染背景。
* 本应用**不会**在后台扫描您未授权的其他磁盘目录，也**不会**将您的任何照片或文件上传至任何服务器。

### 4. 网络连接说明
本应用的核心功能（时钟、世界时钟、闹钟、计时器、秒表、番茄钟、睡眠模式、本地壁纸轮播）均可在**完全离线**的环境下正常运行。

### 5. 隐私政策的变更
如果我们对本隐私政策进行任何更新，我们将在本页面发布最新版本并更新顶部的“最后更新”日期。

### 6. 联系我们
如果您对本隐私政策或本应用的数据保护有任何疑问，请通过 Microsoft Store 应用页面上的开发者支持联系方式与我们取得联系。

## English Version: World Clock Pro: Desktop Time, Alarms & Focus Timer Privacy Policy

**Effective Date: November 6, 2026**  
**Last Updated: November 6, 2026**

Thank you for using **World Clock Pro: Desktop Time, Alarms & Focus Timer** ("the Application"). We respect and protect your privacy. This Privacy Policy explains how the Application handles your information.

### 1. Zero Personal Data Collection
**World Clock Pro: Desktop Time, Alarms & Focus Timer** is a **local-first desktop utility**:
* We **do not** collect, transmit, store, or share any personal data, device identifiers, IP addresses, usage telemetry, or location data on any external servers.
* The Application contains **no** third-party advertising SDKs, analytics trackers, or profiling scripts.
* No user account or sign-in is required to use any feature of the Application.

### 2. Local Preferences Storage
To remember your user preferences (such as your selected world clock cities, alarms, visual theme, language setting, and local wallpaper file paths), the Application stores a lightweight configuration file (`settings.json`) strictly inside your local Windows user configuration directory (`%APPDATA%` / local package storage).
* All configuration data remains 100% on your local device.
* You can delete this data at any time by resetting or uninstalling the Application.

### 3. Local Photo & Folder Access
When you use the Custom Wallpaper or Wallpaper Carousel feature:
* The Application only reads the image files (`.png`, `.jpg`, `.jpeg`, `.bmp`) or photo folders that you explicitly select via the Windows file/folder dialog or drag-and-drop into the Application window.
* Your photos are decoded solely in local memory for on-screen background rendering and are **never** uploaded, copied, or transmitted anywhere.

### 4. Offline Operation
All core features of **World Clock Pro: Desktop Time, Alarms & Focus Timer** (Clocks, World Clocks, Alarms, Timers, Stopwatch, Pomodoro Tracker, Sleep Mode, and Wallpaper Carousel) operate completely offline.

### 5. Contact Us
If you have any questions about this Privacy Policy, please contact us via the Publisher Support link on the Microsoft Store listing page.
